STEP 1 ドメイン取得（Cloudflare Registrar） 所要 15分
1-1 Cloudflare アカウントを作成する

https://dash.cloudflare.com/sign-up にアクセス

  • メールアドレスとパスワードを入力して登録
  • 確認メールのリンクをクリックして認証完了
なぜ Cloudflare？
後でホスティングを GitHub Pages → Cloudflare Pages に移行するとき、 DNS の向き先を変えるだけで完結する。お名前.com 等だと余分な操作が増える。
1-2 teiji-tango.com を購入する
  • ダッシュボード左メニュー → 「Domain Registration」 → 「Register domains」
  • 検索ボックスに teiji-tango.com と入力して検索
  • 取得可能なら「Purchase」→ クレジットカード情報を入力して完了
料金目安：.com は年 約1,100円（仲介マージンなしの原価）。 自動更新がデフォルトなので設定を確認しておく。
STEP 2 Git リポジトリ作成 & GitHub Pages 公開 所要 30分 + DNS反映待ち（最大24時間）
2-1 GitHub でリポジトリを作成する
  • https://github.com/new にアクセス
  • Repository name: teiji-tango
  • Visibility: Public（GitHub Pages 無料プランは Public 必須）
  • 「Create repository」をクリック
2-2 ローカルのコードを push する

teiji-tango フォルダでターミナルを開き、以下を実行：

git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/あなたのユーザー名/teiji-tango.git
git push -u origin main
注意：node_modules/ はアップロード不要。 push 前に .gitignore に node_modules が含まれているか確認。
2-3 GitHub Pages を有効にする
  • リポジトリページ → 上部メニュー「Settings」
  • 左サイドバー → 「Pages」
  • Source: 「Deploy from a branch」
  • Branch: main / / (root) → 「Save」

数分後に https://ユーザー名.github.io/teiji-tango/ でアクセス可能になる。

2-4 Cloudflare で DNS レコードを追加する

Cloudflare ダッシュボード → 取得したドメイン → 「DNS」→「Records」→「Add record」

以下の5件を追加：

Type: A      Name: @    Value: 185.199.108.153   Proxy: DNS only
Type: A      Name: @    Value: 185.199.109.153   Proxy: DNS only
Type: A      Name: @    Value: 185.199.110.153   Proxy: DNS only
Type: A      Name: @    Value: 185.199.111.153   Proxy: DNS only
Type: CNAME  Name: www  Value: ユーザー名.github.io  Proxy: DNS only
「Proxy: DNS only」（雲アイコンをグレーに） にすること。 オレンジ（Proxied）のままだと GitHub Pages の HTTPS 証明書が取得できない。
2-5 GitHub Pages にカスタムドメインを設定する
  • GitHub リポジトリ → Settings → Pages
  • 「Custom domain」欄に teiji-tango.com を入力 → 「Save」
  • DNS チェックが完了したら（緑チェック表示）「Enforce HTTPS」にチェックを入れる
DNS 反映には最大 24 時間かかる。翌日に確認するのが確実。
完了後 https://teiji-tango.com でアクセスできる。
STEP 3 Cloudflare Web Analytics の設置 所要 10分
3-1 サイトを登録してビーコンスニペットを発行する
  • Cloudflare ダッシュボード → 左メニュー「Analytics & Logs」→「Web Analytics」
  • 「Add a site」をクリック → teiji-tango.com を入力して追加
  • 発行された <script> タグ（下記のような形）をコピーする
<script defer src='https://static.cloudflareinsights.com/beacon.min.js'
  data-cf-beacon='{"token": "（ここにトークンが入る）"}'></script>
なぜ Cloudflare Web Analytics？
Google Analytics と違って Cookie を使わず、ユーザーの同意バナーが不要。 無料で、PV数・訪問元・国別アクセスなどの基本指標が見られれば十分なこの規模のサイトに最適。 Cloudflare Pages に移行した後もそのまま使い続けられる。
3-2 index.html にスニペットを貼り付けて push する
  • index.html の </head> 直前にコピーしたタグを貼り付ける
  • STEP 4 の方法でコミット & push して公開
  • 反映後、数分〜数時間ほどでダッシュボードにアクセスが計測され始める
計測が始まらなくても焦らない。初回はデータが集まるまで多少のタイムラグがある。 https://teiji-tango.com に自分でアクセスしてみて、ダッシュボードの数字が動くか確認するとよい。
STEP 4 公開後の更新方法 毎回 1分
4-1 コードを変更したら push するだけ 
git add .
git commit -m "変更内容のメモ"
git push

push 後 1〜2分で teiji-tango.com に反映される。

STEP 5（将来） Cloudflare Pages への移行 月1万PV超えたら検討 / 所要30分
5-1 Cloudflare Pages にプロジェクトを作成する
  • Cloudflare ダッシュボード → 左メニュー「Workers & Pages」
  • 「Pages」タブ → 「Create application」→「Connect to Git」
  • GitHub と連携 → teiji-tango リポジトリを選択
  • Build command: 空白（静的サイトなのでビルド不要）
  • Build output directory: /（ルート）
  • 「Save and Deploy」をクリック
5-2 カスタムドメインを Cloudflare Pages に向ける
  • プロジェクトの「Custom domain」→「Set up custom domain」
  • teiji-tango.com を入力 → 「Activate domain」
  • DNS レコードは Cloudflare が自動で書き換えてくれる（手動操作不要）
URL は変わりません。 SEO・ブックマーク・シェアされたリンクすべてそのまま。 ダウンタイムもほぼゼロ。Web Analytics の計測も中断なく継続される。
5-3 GitHub Pages のカスタムドメイン設定を削除する（後片付け）
  • GitHub リポジトリ → Settings → Pages → Custom domain を空欄に → Save
  • これで Cloudflare Pages 一本化が完了
