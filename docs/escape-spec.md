## ゲーム概要

「サラリーマン（👔シャツ）が定時に帰りたいのに、次々と飛んでくる仕事を避け続ける」2Dドッジゲーム。
上司（ハゲ親父）・炎上案件🔥・緊急メール✉️・大量書類📄を避け、ビール🍺を取って加点。生存時間＋ビール点数のスコアを競う。

- HTML5 Canvas 2D + `requestAnimationFrame`。フレームワークなし・サーバーなし
- ファイルは `index.html`（Canvasと遊び方モーダルのみ）/ `style.css` / `game.js`（約780行）の3点構成
- UI はほぼすべて Canvas 描画（遊び方モーダルのみ DOM）

## 画面・ステート

| 項目 | 値 |
|------|-----|
| Canvas 内部解像度 | 600×600px 固定。表示は `min(600px, 100vw)` でモバイル縮小 |
| ステート遷移 | `START →(STARTボタン/SPACE)→ PLAYING →(衝突)→ OVER →(RESTART/SPACE)→ PLAYING` |
| クロスリンク | スタート／ゲームオーバー画面にタンゴへのリンク（Canvas上のヒット判定）。フッターにも各ゲームリンク |

## 操作

| 操作 | 動作 |
|------|------|
| マウス移動 | プレーヤーが直接追従（PC メイン操作）。プレイ中はカーソル非表示 |
| タッチドラッグ | **相対ドラッグ**: 指を置いた起点からの移動量分だけプレーヤーが動く。画面外（canvas外）へのドラッグも document レベルのリスナーで追従 |
| WASD / 矢印キー | 300px/s で移動（補助） |
| SPACE | スタート / リスタート |

**相対ドラッグを採用した理由**: 絶対追従だと指でプレーヤーが隠れる・指を置き直すとワープする問題があるため。

## プレーヤー

- 初期サイズ 20px、`20 + 経過秒 × 0.75 × growthMult` で時間とともに巨大化（＝難化要素）
- 画面端でクランプ。衝突判定は AABB

## 敵オブジェクト

`enemies[]` にビールも含めて一元管理し、`type` フィールドで分岐する設計。

| type | 見た目 | 出現率 | サイズ | 速度倍率 | 判定 | 備考 |
|------|--------|--------|--------|---------|------|------|
| normal | ハゲ親父（Canvas手描き） | 65% | 15〜45px | 1.0× | **円** | 顔が丸いため円判定（AABBだと角で不公平） |
| beer | 🍺 | 10% | 18〜36px | 0.9× | AABB | 接触で **+10点**、消滅。`+10🍺` フロートエフェクト表示 |
| mail | ✉️ | 12% | 13〜26px | 1.15× | AABB | 小さく速い |
| fire | 🔥 | 7% | 36〜58px | 1.65× | AABB×0.65 | 炎は細長いので判定を小さめに補正（hitMult） |
| doc | 📄 | 6% | 30〜52px | 0.58× | AABB | 大きく遅い |

### スポーン制御

- 4辺のランダム位置から出現し、画面中心方向±ランダム角で飛ぶ
- **コーナー逃げ対策**: 辺の外側1/3から出た敵は角度ブレを ±22.5°、内側1/3は ±45° に制限 → 全敵が必ず画面内を横断する
- スポーン間隔: `max(250, 550 − 経過秒×6) / spawnRate` ms（時間で加速）
- 敵速度: `rand(100+経過秒×1.5, 200+経過秒×2) × speedMult × type倍率` px/s
- ゲーム開始直後に1体即出現（開始直後の空白時間対策）
- 画面外マージン400pxを超えた敵は配列から削除

## スコアとゲームオーバー

- `スコア = floor(生存秒数) + ビール点数`
- ハイスコアは `localStorage['teiji-escape-highScore']`
- ゲームオーバー画面: 通常は赤テーマ、ハイスコア更新時は金テーマ＋「★ NEW HIGH SCORE！★」バナー
- シェア: X / LINE ボタン（Canvas上）。日英対応のテキスト＋ハッシュタグ `#定時退社エスケープ` / `#TeijiEscape`

## メインループの注意点

- delta time は **50ms でキャップ**（`Math.min(dt, 0.05)`）: タブ復帰時に巨大な dt が渡されて敵がワープするのを防ぐ

## i18n

- `LANG = navigator.language` で ja / en 自動判定（手動切替なし）
- HTML は日本語デフォルト、英語時のみ `applyI18n()` で DOM とCanvas文言を差し替え
- 遊び方モーダルは初回訪問時に自動表示（`localStorage['teiji-escape-howto-seen']` と `HOWTO_VERSION` の比較。バージョンを上げると再表示される）
