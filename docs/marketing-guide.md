# 定時退社タンゴ マーケティングガイド

最大の武器は**シェア文の絵文字グリッド**。Wordle が世界を席巻したのと同じ仕組みが既に実装済み。
「定時退社した！」という体験自体が、働く人全員に刺さるコンセプト。

## PHASE 0：公開前仕込み（公開 3〜7日前）

目標：**公開日に最初の流入を作れる状態**にする

### 1回限りアクション

#### X（旧Twitter）専用アカウントを作る `チャネル: X`
- アカウント名：`@teiji_tango`（または近いもの）
- プロフィール：「毎日1問！働く人のための論理パズル 👔🍺 定時退社しよう」
- ヘッダー画像にゲーム画面のスクショを設定
- プロフィール URL に `https://teiji-tango.com` を設定

> **なぜ専用アカウント？**
> ゲームの結果シェアが毎日流れてくる場所を作ることで、プレイヤーが「ここに投稿する」コミュニティが育つ。

#### OGP画像を作る（SNS シェア時のカード画像）`チャネル: X / LINE`
- サイズ：1200×630px の PNG → `icons/ogp.png` に配置するだけで自動適用
- **Canva（無料）** で作るのが最速。テンプレート「Twitter Card」で検索
- 背景：濃紺（#1a1a2e）／ゲームタイトル大きく／👔🍺 のアイコン
- キャッチコピー例：「今日も定時退社できた？毎日更新の論理パズル」

> **これがないと** SNS でシェアしたとき文字だけになり、クリック率が 3〜5 分の 1 になる。**最優先で準備。**

#### note.com に「作った経緯」記事を書いておく `チャネル: note / はてブ`

タイトル例：**「会社員が Wordle に影響を受けて『定時退社パズル』を作った話」**

構成：
- なぜ作ったか（残業文化への皮肉・ゲームが好き）
- どう作ったか（技術の話は軽く。開発期間・使った技術）
- 遊んでほしい（URL を末尾に）

> 記事は公開前に下書き保存しておき、**公開日に同時に投稿**するのがベスト。

## PHASE 1：公開当日（ゼロ日目）

目標：**最初の 100 人**に届ける。種火を作る 1 日。

### 午前：X で公開ツイートを投稿する `チャネル: X`

```
🎉 「定時退社タンゴ」をリリースしました！

👔と🍺を並べる毎日更新の論理パズルです。
Wordle 感覚で、5〜10分でサクッと遊べます。

✅ 無料・インストール不要
✅ 毎日新しい問題
✅ ヒント機能あり

▶ https://teiji-tango.com

#定時退社タンゴ #パズル #ゲーム #Wordle好きに届け
```

> ゲームのスクショ画像（グリッドが写っているもの）を 1 枚添付するとエンゲージメントが上がる。

### 午前：note 記事を公開する `チャネル: note`
- 下書きを公開に変更
- 公開と同時に X でも記事 URL を紹介ツイート
- タグ：`#ゲーム制作` `#個人開発` `#パズル`

### 午後：Zenn または Qiita に技術記事を投稿する `チャネル: Zenn / Qiita / はてブ`

タイトル例：**「静的HTML だけで毎日更新パズルゲームを作った（150問自動生成・PWA対応）」**

- 技術的な話をメインに（バックエンドなし・バックトラッキングで問題生成・テスト 2,500 件）
- エンジニア読者がシェアしてくれると一気に拡散する

> **はてブ効果**：Zenn/Qiita の記事がはてブで 3 ブックマーク以上つくと新着に載り、そこからさらに流入が来るケースが多い。

### 当日：友人・知人 5〜10 人に直接 URL を送る `チャネル: LINE / X DM`
- 「作ったゲームリリースした！感想教えて」と個人的に送る
- フィードバックが来れば改善に役立つ
- 子どもにも遊ばせてみる（ファミリー層の反応チェック）

## PHASE 2：Day 2〜14 習慣化と口コミの種まき

目標：**毎日プレイヤー 50 人以上**。自分がコンテンツを作り続ける期間。

### 毎日：X で自分の今日の結果をシェアする `チャネル: X`

ゲームのシェアボタンで出てくる絵文字グリッドをそのまま投稿。コメントを 1 行添えるだけでいい。

```
定時退社タンゴ Day 12（通常・初級）
👔🍺👔🍺👔🍺
🍺👔🍺👔🍺👔
👔🍺👔🍺👔🍺
🍺👔🍺👔🍺👔
👔🍺👔🍺👔🍺
🍺👔🍺👔🍺👔
⏱ 1:47 | ヒント0回

今日も定時退社！ https://teiji-tango.com
#定時退社タンゴ
```

> 毎日投稿することで「今日も更新されてる」という信頼感が生まれる。フォロワーが少なくても継続が重要。

### 毎日：シェアしてくれた人に必ずリプライする `チャネル: X`
- `#定時退社タンゴ` で検索して投稿している人を探す
- 「ありがとうございます！」「明日も定時退社しよう！」など一言リプライ
- 作者が反応してくれると嬉しくて継続プレイヤーになりやすい

### 週 1 回：パズル・ゲーム系コミュニティに投稿する `チャネル: Reddit`

投稿先と文章のトーンを変える：
- **r/wordlegames**：「Made a Japanese Wordle-style puzzle about work-life balance 👔🍺」
- **r/japanlife**：「Made a daily puzzle game inspired by Japan's work culture」
- **r/webgames**：自作ゲーム投稿OK（各 subreddit のルール確認必須）

### 1 回：Product Hunt に投稿する `チャネル: Product Hunt`
- タイトル：**Teiji Tango**
- 説明：「A daily Japanese logic puzzle about work-life balance. Place 👔 and 🍺 by the rules — and escape on time!」
- タグ：Games, Puzzle, Productivity
- **投稿は平日の午前 0 時（US 東海岸時間）**に合わせると Daily Rank に乗りやすい
- 投稿したら X で「Product Hunt に掲載されました！」と告知

## PHASE 3：Month 1〜3 SEO と継続流入の土台を作る

目標：**月間 5,000〜10,000 PV**。検索で勝手に人が来る状態を作る。

### 1 回：Google Search Console に登録する `チャネル: Google`
1. [search.google.com/search-console](https://search.google.com/search-console) にアクセス
2. 「URLプレフィックス」で `https://teiji-tango.com` を登録
3. HTML タグで確認（`index.html` の `<head>` にメタタグを貼るだけ）
4. `sitemap.xml` を作って送信

> 登録後 1〜2 週間でクロールされ始める。「どのキーワードで検索されているか」がわかるようになる。

### 月 1〜2 回：note で攻略・ネタ記事を書く `チャネル: note / X`

記事ネタ例：
- 「定時退社タンゴの攻略法・コツまとめ」
- 「ノーヒントでクリアするための考え方」
- 「実績『三冠達成』の取り方」
- 「プレイヤー数が○人になりました」（マイルストーン報告）

> 攻略記事は「定時退社タンゴ 攻略」などで検索した人が来るため、SEO 効果が高い。

### 週 1 回：プレイヤーの声を集めてゲームを改善する `チャネル: X`
- X で「難しすぎる」「もっとこうして欲しい」などの声に反応
- 改善したら「○○さんのフィードバックでアップデートしました！」とツイート
- これがユーザーの帰属意識を高め、口コミに繋がる

## PHASE 4：3ヶ月以降 収益化フェーズ（月 1 万 PV 達成後）

目標：**月 1,000〜10,000 円**の収益。ドメイン代をペイできる状態。

### Google AdSense を申請・設置する
- 配置場所：ゲームエリア下のバナー（320×50px）が最も UX を損なわない
- 結果モーダルを閉じた後に広告表示するのもアリ

> **収益目安**：月 1 万 PV で月 500〜2,000 円。まずはドメイン代（年 1,100 円）回収を目標に。

### Android アプリ化（TWA）で Play ストアに出す
- PWA は **TWA（Trusted Web Activity）** という方法で Play ストアに出せる
- Bubblewrap（Google 製 CLI）を使えばほぼコード変更なし
- Play ストア登録料：$25（一回払い）
- AdMob（アプリ内広告）は Web 広告より単価が高い
