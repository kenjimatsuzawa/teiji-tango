## ゲーム概要

ブラック企業の出口暗証番号（3桁・各桁すべて異なる数字）を当てる数字野球（ヒット&ブロー）ゲーム。
試行回数無制限。**コードはページ読み込みごとにランダム生成**（タンゴのような日替わり固定ではない）。

- ファイルは `index.html` / `style.css` / `game.js`（約500行）の3点構成。フレームワーク・サーバーなし
- シリーズ名の変遷: 「定時退社キー」として開発開始 → 「定時退社ロック」に改名（開発ソースのフォルダ名 `teiji-key/` に旧名が残っている）

## コアロジック

| 関数 | 内容 |
|------|------|
| `getRandomCode()` | 0〜9 から重複なしで3桁を生成。ページロード時に1回だけ呼ばれ `SECRET` に固定 |
| `evaluate(secret, guess)` | S/B 判定。used フラグ方式で重複数字の入力にも正しく対応 |

### S / B ルール

- **S（ストライク）**: 数字・位置ともに正解
- **B（ボール）**: 数字は含まれるが位置が違う
- **3S0B = 脱出成功**（勝利後は入力ボタンが disabled になる。再挑戦はリロード）

## UI 構成（lock/index.html）

| 要素 | 内容 |
|------|------|
| 入力表示 | 3つの `digit-box`（`_` → 入力数字） |
| テンキー | 0〜9 ボタン + ⌫消す + 解読！。物理キーボード（0-9 / Backspace / Enter）も対応 |
| 履歴 | 新しい試行が上に挿入される。`3 5 7 → 2S 0B` 形式、正解行は `🔓 OPEN!` |
| フッター | タンゴ・エスケープへのクロスリンク |

## 結果ポップアップ

「解読！」押下ごとに画面中央にポップアップ表示。

- 入力数字は絵文字表示（`NUM_EMOJI`: 0️⃣〜9️⃣）
- 結果: `xS`（緑）`xB`（黄）。正解時は `🔓 OPEN!` → 1.4秒後に自動クローズ → 脱出成功モーダル
- ヒント文（1人称思考スタイル、日英対応、S/Bラベル付き）:

| 状態 | 日本語 |
|------|--------|
| 0S0B | これらの数字はどこにも含まれないようだ... |
| xS | `xS`…x つの数字の場所が正しいようだ... |
| xB | `xB`…x つの数字が答えに含まれるようだ...ただ場所が違う |

- 閉じ方: ×ボタン / 欄外タップ / 次の数字入力

## メモ機能

| 機能 | 内容 |
|------|------|
| 数字チップ（0〜9） | タップで3状態サイクル: 不明（灰）→ ✕ない（赤）→ ◯ある（黄）。`digitState[10]` で管理 |
| 位置スロット（①②③） | タップでピッカーを開き候補数字を複数選択。「確定にする」で1桁に絞って確定（緑）表示。`posState[3] = {digits[], confirmed}` |

## 勝利モーダル

試行回数・答えを表示。×ボタンで閉じる。𝕏シェアボタンあり。

## シェア機能

試行履歴を絵文字グリッド化して X (Twitter) intent で投稿:

```
🔒 定時退社ロック
n回で脱出！

3️⃣5️⃣7️⃣: 2🏏 0⚾
...

teiji-tango.com/lock/
```

## i18n

- `LANG = navigator.language` で ja / en 自動判定 + ヘッダーの **EN/JA トグルボタンで手動切替可**（シリーズ中ロックのみ手動切替あり）
- `TRANSLATIONS` オブジェクト + `data-i18n` 属性 + `applyLang()` で全テキスト差し替え
- 遊び方モーダルは `HOWTO_HTML.ja / .en` を JS で注入

なし（localStorage 未使用）。ベスト記録・遊び方既読管理などは未実装。
